# Scientific companion

Python 3.10 or later and its standard library are sufficient for the original
two-prime companion and the retained verification commands. Full geometric
reconstruction of the sharper global bound additionally requires GNU C++17,
OpenMP and a little-endian Linux environment; see
[the global-bound companion](global_bound/README.md) for the complete routes.
The programs
use every residue modulo M, including zero, and require denominators coprime
to M. Mathematical proofs and the meaning of the certificates are in the
manuscript. See [the reproduction guide](../REPRODUCE.md) for commands and
their verification scopes.

The object store contains sources, complete certificate domains, retained
histograms/log ledgers, analytical partitions and the final 4,410-row
two-prime certificate union. Larger objects use deterministic gzip. Both
the compressed bytes and the uncompressed scientific bytes are hashed and
checked before use.

[provenance.json](provenance.json) maps public logical batches to the original
relative source locators and hashes. Original locators identify antecedents;
runtime paths use the public batch layout. Public mathematical-note
projections omit control and review prose. Source rendering removes control
documentation and comments; mathematical statements and functions are
preserved. Relative path and digest bindings are relinked throughout the
dependency graph. The original and derived hashes are distinct and explicit.
[portable_source_map.json](portable_source_map.json) additionally identifies
the actual import adapters used by replay.

The original retained verifier keeps its narrower scope. The original complete
two-prime reconstruction regenerates every consumed computational premise,
including analytical bounds, inventories, all 4,596 semiprime histograms
and ledgers, and physical controls. All outputs agree with their archived
mathematical values and bytes in normal and optimized modes.

[reconstruction/index.json](reconstruction/index.json) binds the supplemental
evidence and observed runs. All central aggregate thresholds and proper gcd
strata, together with the complete semiprime/base-six/sixth-power central
prefixes, passed a distinct legal-pair enumeration. The semiprime logs passed
a separate integer enclosure recipe. The mathematical infinite estimates,
far-envelope domination and imported binary theorem remain proof dependencies.

The four-case semiprime command is still the default short reconstruction.
Use the full reconstruction driver to repeat the complete work, or the
complete-evidence checker to validate the packaged records and log bounds.

Optional replay materializes verified sources/data in `replay_work/NAME`.
NAME must be new: any existing directory is rejected before writes or
scientific launch. A replay creates new evidence and does not reclassify it
as a historical execution. Code, companion data and documentation use the
repository's MIT license; the manuscript uses its separately stated license.
