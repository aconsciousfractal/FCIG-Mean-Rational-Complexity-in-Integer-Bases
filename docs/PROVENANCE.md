# Scientific provenance

The companion has 116 relative locators and 111 distinct objects.
[provenance.json](../companion/provenance.json) gives each public locator,
kind, batch, original relative locator/digest/size, actual public uncompressed
digest/size, storage locator and actual compressed digest/size.
[portable_source_map.json](../companion/portable_source_map.json) identifies
the derived relative import adapters.

The public object store contains 515,818,707 uncompressed bytes, stored in
131,181,026 bytes (gzip plus plain source objects); the largest stored object
is 38,002,955 bytes. Every stored object is checked; compressed objects are
also checked after decompression.
Gzip carries zero modification time and no original filename.
Compressed bytes are distributed identities; cross-Python-version
recompression identity is not asserted.
Git preserves every companion file byte for byte with text conversion and
external filters disabled. Some retained plain objects and source adapters
use CRLF; their distributed digests refer to those exact bytes. Reader
documentation, workflow and manuscript sources use LF.

Selected content includes the complete prime-power/semiprime/aggregate
finite premises and domains, analytical partitions, two inventory outputs,
calendar inputs, final branch data and their verification records.
The prime reference panel is an author-generated mathematical table.

The four mathematical notes used by analytical producers are projections
of the relevant proof exposition. Control paragraphs are omitted.
Source comments/docstrings and local-path routing are made reader-facing;
mathematical functions remain unchanged except declared locator/hash strings.
The dependency graph of source/data digests is acyclic, and affected pins
are relinked consistently to the actual exported bytes.
All mathematical numbers, arrays, histograms and logarithmic enclosures
are preserved. A frontier control digest is deliberately omitted.

An original digest is never assigned to a redacted public file.
Original identities describe provenance; the exported identities describe
the actual reader tree. Relinking does not assert that historical jobs
were executed with exported sources. Complete source materialization is
verified by the replay driver, which requires a fresh work directory.

Attempts, operating instructions, private receipts, manuscript drafts,
review reports and machine paths are outside this package.
No third-party paper or implementation is bundled.
[License scopes](../LICENSE_SCOPE.md) apply to original code/data and manuscript.

and adds 58 reader-facing evidence records in
[reconstruction/index.json](../companion/reconstruction/index.json).

driver. Complete evidence supplements use the same MIT license.

142091058 stored bytes; the largest is 38002955 bytes.
These totals cover objects only. [Reproduction](../REPRODUCE.md) specifies the
full and short command scopes; verification of published records is distinct
from rerunning their scientific producers.
